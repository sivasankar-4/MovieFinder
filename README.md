# 🎬 Movie Finder

A React-based movie discovery application that allows users to search for movies and view detailed information using the OMDb API.

---

## 🚀 Features

- 🔍 Search movies by title
- 🎞 View movie posters
- 📄 Detailed movie information (Year, Genre, Actors, Plot, IMDb Rating)
- ⏳ Loading state handling
- ❌ Error handling for invalid searches
- 🖥 Responsive design
- 🎨 Clean UI with modal overlay for details

---

## 🛠 Tech Stack

- React (Functional Components + Hooks)
- JavaScript
- OMDb API
- CSS
- Git & GitHub
